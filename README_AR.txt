بُنيان — نسخة ويب تجريبية مبنية على النسخة المرجعية المرفوعة
============================================================

مهم جداً:
- هذه نسخة ويب أولية وليست استبدالاً لنسخة سطح المكتب.
- قاعدة البيانات bunyan.db نُسخت كما هي من الملف المرفوع ولم تُسترجع المشاريع المحذوفة.
- عدد المشاريع عند تجهيز الحزمة: 83. هذا هو العدد الموجود فعلياً في قاعدة البيانات المرفوعة.
- النسخة المكتبية الكاملة لا تزال محفوظة في الأرشيف الأصلي.
- لا ترفع هذه النسخة للاستخدام الرسمي قبل تغيير كلمة المرور والمفتاح السري واختبارها.

وظائف نسخة الويب الأولية:
- تسجيل الدخول باستخدام حسابات قاعدة البيانات نفسها.
- لوحة معلومات وإحصاءات حسب الحالة والمحافظة.
- عرض المشاريع والبحث والتصفية.
- تفاصيل المشروع والتحديثات والمرفقات والمراسلات المسجلة.
- إضافة مشروع وتعديل بياناته حسب الصلاحيات الموجودة.
- تصدير بيانات المشاريع CSV المتوافق مع Excel.
- فحص صحة قاعدة البيانات من /health.

تشغيل محلي للتجربة:
1) تثبيت Python 3.11.
2) فتح الطرفية داخل هذا المجلد.
3) تنفيذ: pip install -r requirements.txt
4) تنفيذ: python app.py
5) فتح: http://127.0.0.1:5000
